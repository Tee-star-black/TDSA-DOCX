# Private source review

Original source PDFs, filenames, facility metadata, hashes, dates and source-specific review notes belong outside this public repository.

Use a private catalogue at `.data/catalogue.json`. Its entry schema matches the synthetic `data/catalogue.json`; the server prefers the private catalogue when present. This catalogue is provided separately from the code.

Before publication, check duplicates and near-duplicates, document titles and identifiers, effective/review dates, ownership and branding, missing pages, scans, handwriting and completed records. Preserve source files unchanged and record explicit owner decisions. Import is not clinical approval. Restricted entries must not be exposed by the viewer.
